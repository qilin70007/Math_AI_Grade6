# 数芽 · 上海初中数学 AI 私教

给上海初中学生个人使用的本地优先数学学习 PWA。当前使用者默认为六年级，产品围绕“今日任务 → 互动课堂 → 掌握证据 → 错题复习 → 家长看板”形成闭环。

## 已实现

- 今日 20 分钟学习计划与到期复习提醒
- 分关卡互动课堂、分层提示、即时反馈和结课报告
- 上海初中数学六至九年级、八个学期的新版知识地图
- 单列“小初衔接”，补足旧版“数的整除、分数”两章
- 34 个单元、245 个可独立追踪的能力点与掌握度状态
- 错题录入、拍照留档、错因分类和复习状态
- 家长 PIN 看板、周学习统计、薄弱点和课程报告
- 本机持久化、JSON 数据备份/恢复、离线安装
- 手机、平板和桌面响应式布局

当前互动课堂使用可复核的本地规则引擎，确保演示无需 API Key 即可运行。后续接入大模型时，建议通过服务端代理完成，避免把密钥放在浏览器中；数学答案仍应由确定性规则校验。

## 本地运行

```bash
npm start
```

打开 `http://localhost:4173`。家长模式初始 PIN 为 `2609`，首次进入后可修改。

## 检查

```bash
npm test
npm run check
```

## 数据说明

- 学习数据存储在浏览器 `localStorage`。
- 错题图片存储在浏览器 `IndexedDB`，避免挤占普通配置空间。
- 更换设备前请在家长看板中导出备份文件。
- 六上至九上按上海新版教材章节序列整理；小初衔接保留旧版核心内容。
- 九下标记为“新版预备”，需在正式教材发放后按学校实际目录逐节校准。
- 旧备份恢复后会自动补齐新增知识点，不覆盖已有掌握度、课堂和错题记录。
