# 数芽 · 上海初中数学 AI 私教

给上海初中学生个人使用的本地优先数学学习 PWA。当前使用者默认为六年级，产品围绕“今日任务 → 互动课堂 → 掌握证据 → 错题复习 → 家长看板”形成闭环。

## 已实现

- 今日 20 分钟学习计划与到期复习提醒
- 任意知识点的开放式大模型课堂：自由回答、追问、分层提示与结构化结课报告
- 可分别选择 OpenAI、DeepSeek、Kimi、智谱 GLM、腾讯混元用于教学和拍照识题
- 保留无需 API Key 的最大公因数离线示范课，模型不可用时仍能学习
- 上海初中数学六至九年级、八个学期的新版知识地图
- 单列“小初衔接”，补足旧版“数的整除、分数”两章
- 34 个单元、245 个可独立追踪的能力点与掌握度状态
- 错题拍照 OCR：自动提取题干、学生答案、错因、正确方法和对应知识点，核对后入库
- 错题录入、原图留档、错因分类、AI 专项讲解和复习状态
- 家长 PIN 看板、周学习统计、薄弱点和课程报告
- 本机持久化、JSON 数据备份/恢复、离线安装
- 联网时优先获取最新版；部署更新后自动刷新，离线时使用本机缓存
- 手机、平板和桌面响应式布局

大模型功能采用“GitHub Pages 前端 + Cloudflare Worker 服务端”结构。默认使用 DeepSeek 的 `deepseek-flash` 同时完成文字教学和拍照识题，只需一个 DeepSeek API Key。浏览器只保存服务地址和模型选择，API Key 仅放在 Worker Secret 中。各厂商返回会统一转换并校验为数芽需要的结构；OpenAI 请求设置 `store: false`。前端不会发送孩子称呼、学校或家长 PIN。第一次使用请按 [AI_SETUP.md](./AI_SETUP.md) 完成服务端配置。

## 本地运行

```bash
npm start
```

打开 `http://localhost:4173`。家长模式初始 PIN 为 `2609`，首次进入后可修改。

## 检查

```bash
npm test
npm run check
```

## 开启 AI 功能

完整步骤见 [多模型 AI 课堂与拍照识题配置](./AI_SETUP.md)。部署 Worker、添加 `DEEPSEEK_API_KEY` 后，在“家长 → 学习设置”中填写服务地址并测试连接；教学与 OCR 默认均选择 DeepSeek。

服务端提供：

- `GET /health`：配置与连通性检查
- `POST /api/tutor`：开放式教学、分层提示和结课报告
- `POST /api/ocr`：数学图片识别与课程知识点映射

## 数据说明

- 学习数据存储在浏览器 `localStorage`。
- 错题图片存储在浏览器 `IndexedDB`，避免挤占普通配置空间。
- OCR 只在用户主动点击后发送压缩图片，识别结果必须核对后才会保存。
- 更换设备前请在家长看板中导出备份文件。
- 六上至九上按上海新版教材章节序列整理；小初衔接保留旧版核心内容。
- 九下标记为“新版预备”，需在正式教材发放后按学校实际目录逐节校准。
- 旧备份恢复后会自动补齐新增知识点，不覆盖已有掌握度、课堂和错题记录。
